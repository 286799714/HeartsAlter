# 服务端权威的四人红心大战回合

牌局规则、洗牌发牌、合法出牌、墩胜负、计分和筹码结算全部在 Colyseus 服务端执行；联网客户端只提交意图并渲染同步结果。手牌不放进公开状态，而是通过针对玩家的私有消息发送。这个边界避免客户端作弊，也让 Godot 客户端可以在不泄露对手手牌的情况下重连恢复。客户端保留一个明确标注的离线牌面/动画预览，用于服务器不可用时检查资源与 tween；该预览不参与联网对局，也不向服务端伪造状态。

本 demo 采用不换牌的单回合变体，以保持“发牌→出牌→结算”的流程紧凑；首墩固定由梅花 2 领出，移除射月规则。默认底注为 100，但房间可在创建时配置其他正整数底注。并列最高分玩家全部视为请客玩家；其余玩家按点数加权领取奖池，零权重或异常的边界情况使用确定性的均分回退以保证奖池守恒。

为了先用一个客户端验证完整流程，房间选项 `bots: true` 提供单人演示模式：服务端创建 3 个演示机器人，机器人仍使用同一套合法出牌与结算路径，只将其轮次响应时间缩短到约 600ms。该模式限制为一个真实连接；默认不传 `bots` 时仍要求四名真人。
